## 工具简介

apate 是 Windows 文件格式伪装工具，提供内置 MP4 面具、自定义面具及简易文件头模式。

本仓库：[yizhixiaochuan1/apate](https://github.com/yizhixiaochuan1/apate)
原项目：[rippod/apate](https://github.com/rippod/apate)

## 当前源码版本：v1.5.0

本版修复了误还原、原地写入及批处理异常导致的数据风险，并引入带标识和完整性校验的新格式。

- **始终保留输入文件**：伪装、正常还原、旧版兼容还原都生成另一个文件，不改写或删除原件。
- **不覆盖已有输出**：先写入同目录临时文件，校验和落盘成功后才发布最终文件；写入失败或取消时清理临时文件。
- **新版还原先验证格式**：检查版本、长度、保存的头部和文件名；生成还原结果时核对原始内容的 SHA-256。
- **后台批处理**：支持文件及文件夹拖拽、输入去重、进度、取消和逐项失败详情；目录链接会被跳过，避免递归循环。
- **兼容旧文件**：通过“选项 → 还原旧版文件…”单独处理 v1.4.2 及更早版本生成的文件。

v1.5.0 为源码版本；原项目的 [v1.4.2 下载包](https://github.com/rippod/apate/releases/download/apate.v1.4.2/apate.v1.4.2.zip) 不包含这些修复。请自行编译当前源码，或使用本仓库成功构建的 GitHub Actions 产物。

## 使用方法

### 伪装

1. 默认“一键伪装”使用内置 MP4 面具。将文件或文件夹拖入中间区域即可。
2. “面具伪装”需要先向左侧拖入一个自定义面具，再向中间拖入待处理文件。
3. “简易伪装”提供 EXE、JPG、MP4、MOV 文件头，只改变格式特征，并不会转换文件内容。

自定义面具必须具有扩展名，且大小大于 0、小于 306,783,378 字节（约 293 MiB）。面具会完整载入内存。

例如，处理 `archive.zip` 时生成 `archive.zip.mp4`，并保留 `archive.zip`。目标路径已存在时，该项失败并显示原因，不会覆盖目标。

### 正常还原

将新版伪装文件拖入右侧区域。不需要再次提供面具。

程序使用记录的原始文件名生成结果；即使伪装文件被改名，也能恢复记录的文件名。如果原文件名已存在，则尝试生成 `archive.restored.zip`；该路径也已存在时停止该项，不会覆盖文件。伪装文件始终保留。

普通文件、格式不受支持或校验不通过的文件不会生成还原结果。

### 旧版兼容还原

从“选项 → 还原旧版文件…”选择确定由旧版 apate 生成的文件。

旧格式没有可信的格式标识和校验值，无法自动确认文件身份或内容是否完整。因此正常还原区不会自动尝试旧版算法；兼容入口生成独立结果，保留原件，输出需自行核对。

**v1.4.2 及更早版本不能还原本版的新格式。** 请使用 v1.5.0 及后续兼容版本进行正常还原。

### 批量任务

处理期间可在状态栏查看进度、点击“取消”。失败或跳过的项目可通过“查看失败详情”检查，不会阻止其他文件继续处理。取消会保留已经成功生成的结果和所有原件。

文件夹会先完成枚举，再执行转换；文件数量很多时，收集阶段也可能需要时间。输出与输入位于同一目录，请预留足够空间。

## 性能与格式说明

本版默认保留原件，需要完整读取和写入文件，并对原始内容计算校验值。处理时间随文件大小、面具大小及磁盘速度变化，不再承诺“瞬间完成”。

新格式保存原始文件名、长度、被覆盖头部和校验信息。头部仍采用倒序保存，**不属于加密**。格式伪装不提供内容保密或可信身份认证，也不保证所有软件都会将输出识别为可播放的视频或有效图片。

临时文件使用同目录的 `.apate-*.tmp` 名称。正常失败和取消会清理；进程被强制结束或突然断电后可能遗留临时文件，确认没有任务运行后可删除它们，输入原件不受影响。

## 编译与验证

应用保持 `net6.0-windows` 目标，需要 Windows 和 .NET 6 SDK 编译；运行框架依赖版本需要 .NET 6 桌面运行时。

```powershell
dotnet build apate/apate.csproj --configuration Release
dotnet run --project apate.Tests/apate.Tests.csproj --configuration Release
```

回归验证覆盖：不同原文件/面具长度的往返一致性、空文件、改名后恢复、普通文件误还原、损坏尾部及内容、路径校验、输出冲突、写入失败、取消、旧版兼容、批处理去重及失败隔离。GitHub Actions 在 Linux 和 Windows 执行验证，并在 Windows 构建应用。
